# NovaWorks コーポレートサイト

HTML・CSSで制作している、架空のIT企業「NovaWorks」のコーポレートサイトです。

Home・Service・Case Study・Company・Recruit・Newsの各ページを、1ページで内容が完結する構成にする予定です。現在はHomeのHeroを制作しており、その下のコンテンツや各ページを順次追加していきます。

## 概要

ポートフォリオ掲載用に、架空のIT企業「NovaWorks」のコーポレートサイトを制作しています。

AI・業務自動化・データ分析を通じて企業のDX推進を支援する企業を想定し、サイトのデザインとコーディングに取り組んでいます。

## 主な画面要素

### ヘッダー

- ロゴ
- Home・Service・Case Study・Company・Recruit・Newsのナビゲーション
- Contactボタン

### HomeのHero

- 「テクノロジーで、働くをもっとシンプルに。」というキャッチコピー
- AI・業務自動化・データ分析によるDX支援を紹介するテキスト
- お問い合わせボタン
- 背景画像を使ったメインビジュアル

## 使用技術

- HTML5
- CSS3
- Git
- GitHub

## 実装で工夫した点

### 背景画像とテキストの重ね合わせ

Heroの背景画像の上にHTMLのテキストやボタンを配置しました。文字の背後にぼかしやグラデーションを加え、背景画像の印象を保ちながらテキストを読みやすくしています。

### CSS変数によるスタイル管理

CSS変数を使って、色やコンテンツ幅、ヘッダーの高さなどをまとめて管理しています。共通の値を調整しやすい構成にしました。

### 要素ごとのCSSクラス設計

ヘッダーやナビゲーション、Heroのテキスト、ボタンなどにクラスを付け、それぞれのスタイルをCSSで管理しています。
